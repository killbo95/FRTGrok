Facial Recognition Technology (FRT)

Student Innovation Competition Prototype - Grades 9-10

Privacy Notice: Only demonstrate with people who have given informed consent. Face data is sensitive biometric information. This is an educational demo only.

What this demonstrates:

  • Face Detection: Using browser-based computer vision (face-api.js)
  • Real-time Processing: Detects faces from your device camera
  • Responsible Design: Local processing, no data uploaded
Click "Start Face Detection" to begin (camera permission required)

Technology Behind It

This demo uses face-api.js, a JavaScript library that implements face detection models (based on Tiny Face Detector or SSD MobileNet) that run entirely in the browser.

How it works:

  1. Camera captures video frames
  2. Each frame is analyzed by a neural network trained to detect faces
  3. Bounding boxes are drawn around detected faces
  4. All processing happens locally on your device

Strengths: Works on any device with a browser, no installation needed, privacy-preserving (local processing).

Limitations: Accuracy depends on lighting and face angle; this demo focuses on detection (recognition requires additional enrollment and matching).
